# Number validation samples

Programmatic **value-range** plain cases for `type: number` live in Storybook suites only
(see [`validations-README.md`](../validations-README.md)). There are no YAML fixtures in this
folder — value range schemas are built by `buildValueRangeSchema()` in
`packages/api-doc-viewer/src/stories/shared/value-range-schema-builder.ts`.
